1. 앱 개요

FocusDAW Studio는 여러 개의 스템(분리 음원) 파일을 한 세션에 올려 믹스하고, 그 위에 보컬을 덧녹음(오버더빙)해 한 곡으로 완성하는 데스크톱 앱입니다. 각 트랙의 볼륨·팬·솔로·뮤트·리버브·에코를 조정하고, 마이크 입력을 Audio In 트랙에 실시간으로 녹음한 뒤, 9밴드 그래픽 EQ와 출력 이펙트로 마스터를 다듬어 MP3 또는 WAV로 내보냅니다.

화면 구성

① 타임라인(Arrange)트랙과 파형, 클립, 오토메이션이 놓이는 주 작업 영역입니다.
② 시작 안내 패널트랙이 없을 때만 보입니다. 여기에 파일을 끌어다 놓거나 Import Folder · Import Files · Load demo session으로 시작합니다.
③ Undo / Redo실행 취소와 다시 실행입니다(Ctrl+Z / Ctrl+Y).
④ TIME 줌타임라인의 가로(시간축) 확대·축소입니다.
⑤ AMP 줌파형의 표시 높이(보기 배율)입니다. 실제 볼륨은 바뀌지 않습니다.
⑥ TRACK SIZE트랙 행 높이를 S · M · L 중에서 고릅니다. 크기에 따라 헤더에 보이는 컨트롤 수가 달라집니다.
⑦ 타임라인 미니맵곡 전체에서 현재 보고 있는 구간을 보여 줍니다. 클릭·드래그로 빠르게 이동합니다.
⑧ BPM 표시기앞은 프로젝트 BPM, 뒤는 재생 BPM입니다. 클릭하면 BPM 설정 패널이 열립니다(6장).
⑨ Vari BPM 스위치켜야 재생 BPM으로 실제 재생 속도가 바뀝니다(기본 꺼짐).
⑩ Key 표시기감지·지정된 원곡 키와 이조된 재생 키를 표시합니다. 클릭하면 Key 패널이 열립니다(7장).
⑪ Vari Key 스위치켜야 지정한 반음 오프셋이 실시간 재생에 적용됩니다(기본 꺼짐).
⑫ Mixer별도 창의 믹서 콘솔을 엽니다(F3).
⑬ Export믹스다운 내보내기 창을 엽니다(11장).
⑭ 트랜스포트처음으로 · 정지 · 재생/일시정지 · Repeat · 메트로놈 · 프리롤 · Punch · Record 버튼입니다(4장 · 5장).
⑮ 시간 표시현재 재생 위치와 프로젝트 전체 길이입니다.
⑯ 프로젝트 이름클릭하면 그 자리에서 이름을 고칠 수 있습니다. 창 아래 상태 표시줄에도 같은 이름이 나옵니다.

상단 메뉴 한눈에 보기

Settings 메뉴는 색상 테마, 믹서 창 초기화, 오디오 장치 설정을 담고 있습니다(12장).

트랙 크기 — S · M · L

상단의 TRACK SIZE로 트랙 행 높이를 바꿉니다. 높이가 커질수록 헤더에 더 많은 컨트롤이 펼쳐지므로, 오토메이션 Curve나 Audio In 트랙의 녹음 컨트롤을 다룰 때는 M 또는 L을 쓰는 것이 편합니다.

S (작게)이름·B·S·M 정도만 보입니다. 트랙 수가 많을 때 전체를 한눈에 훑기 좋습니다.
M (기본)볼륨·팬·AUTO·SOURCE까지 보입니다. 일반적인 믹스 작업에 적당합니다.
L (크게)오토메이션의 Reset · Curve와 Audio In 트랙의 입력 포트·MON·LIM·입력 게인까지 모두 보입니다.

파일 트랙 그룹 접기

불러온 스템은 FILE TRACKS 그룹으로 묶입니다. 그룹 머리글의 HIDE / SHOW를 누르면 파일 트랙 전체가 한 줄로 접히고, 그 줄에는 합쳐진 요약 파형과 “n file tracks hidden” 표시가 나타납니다. 녹음 중인 Audio In 트랙에만 집중하고 싶을 때 유용합니다.

주요 작업

  • 프로젝트 새로 만들기 · 열기 · 저장 · 다른 이름으로 저장
  • 오디오 파일 또는 스템 폴더 가져오기
  • 마이크·인터페이스 입력을 Audio In 트랙에 실시간 녹음(오버더빙)
  • 여러 테이크 녹음과 컴프(Comp) 조합, Punch 부분 재녹음
  • 클립 단위 편집(이동·트림·분할·병합·복제·클립 볼륨)
  • 보컬 채널 스트립(HPF · 게이트 · EQ · 컴프레서 · 디에서 · 노이즈 제거)
  • 트랙별 볼륨·팬·솔로·뮤트·리버브·에코와 볼륨 오토메이션
  • 마스터 EQ, 출력 이펙트, 마스터 페이드
  • MP3 또는 WAV로 믹스다운 저장

지원 파일

  • 입력 오디오: .mp3, .wav, .aif, .aiff, .m4a, .ogg, .flac
  • 프로젝트: .focus
  • 녹음·바운스 결과: .wav
  • 출력 오디오: .mp3, .wav
  • MP3 출력 시 제목, 아티스트/작곡가, 앨범, 연도, 날짜, 앨범 아트 태그를 넣을 수 있습니다.

1. App Overview

FocusDAW Studio is a desktop app for mixing a set of separated stems and overdubbing your own vocals on top of them. Balance each track's volume, pan, solo, mute, reverb, and echo; record a live mic input straight onto an Audio In track; then shape the master with a 9-band graphic EQ and output effects and export an MP3 or WAV mixdown.

Screen layout

① Timeline (Arrange)The main work area holding tracks, waveforms, clips, and automation.
② Start panelShown only while the session is empty. Drop files here, or use Import Folder · Import Files · Load demo session.
③ Undo / RedoUndo and redo (Ctrl+Z / Ctrl+Y).
④ TIME zoomHorizontal (time-axis) zoom of the timeline.
⑤ AMP zoomWaveform display height. A visual scale only — it does not change the audio level.
⑥ TRACK SIZETrack row height: S · M · L. Taller rows reveal more header controls.
⑦ Timeline minimapShows which part of the song is in view; click or drag to jump.
⑧ BPM indicatorProject BPM in front, playback BPM behind. Click to open the BPM panel (ch. 6).
⑨ Vari BPM switchMust be on for the playback BPM to actually change the speed (off by default).
⑩ Key indicatorThe detected/assigned original key and the transposed playback key. Click to open the Key panel (ch. 7).
⑪ Vari Key switchMust be on for the semitone offset to apply during playback (off by default).
⑫ MixerOpens the mixer console in its own window (F3).
⑬ ExportOpens the mixdown export dialog (ch. 11).
⑭ TransportReturn to start · Stop · Play/Pause · Repeat · Metronome · Pre-roll · Punch · Record (ch. 4 & 5).
⑮ Time displayCurrent playhead position and total project length.
⑯ Project nameClick to rename in place. The same name appears in the status bar at the bottom.

The menus at a glance

The Settings menu holds color themes, the mixer-window reset, and audio device setup (ch. 12).

Track size — S · M · L

TRACK SIZE at the top changes the row height. Taller rows expose more header controls, so use M or L when working with automation curves or the Audio In recording controls.

S (small)Roughly name, B, S, and M only — best for scanning many tracks at once.
M (default)Adds volume, pan, AUTO, and the SOURCE chip. Suits everyday mixing.
L (large)Also shows automation Reset · Curve and, on Audio In tracks, the input port, MON, LIM, and input gain.

Collapsing the file-track group

Imported stems are grouped under FILE TRACKS. The HIDE / SHOW button on the group header folds every file track into a single row that still shows a combined summary waveform plus an “n file tracks hidden” chip — handy when you want to focus on the Audio In track you are recording.

Key Features

  • Create, open, save, and save-as projects (.focus)
  • Import individual audio files or whole stem folders
  • Record mic/interface input live onto Audio In tracks (overdubbing)
  • Multiple takes with comping, and Punch re-records
  • Clip editing — move, trim, split, merge, duplicate, per-clip volume
  • Vocal channel strip (HPF · gate · EQ · compressor · de-esser · de-noise)
  • Track volume, pan, solo, mute, reverb/echo sends, and volume automation
  • Master EQ, output effects, and master fades
  • Export the final mixdown as MP3 or WAV

Supported Files

  • Input audio: .mp3, .wav, .aif, .aiff, .m4a, .ogg, .flac
  • Project: .focus
  • Recordings and bounces: .wav
  • Output audio: .mp3, .wav
  • MP3 exports can embed Title, Artist/Composer, Album, Year, Date, and Cover Art tags.

2. 시작과 프로젝트

앱 설치와 실행

받으신 설치 파일(FocusDAW-Studio-Setup-x.y.z.exe)을 실행하면 설치가 진행되고, 바탕화면과 시작 메뉴에 FocusDAW Studio 아이콘이 만들어집니다. 이후에는 이 아이콘으로 앱을 실행합니다.

앱을 켜면 마지막에 작업하던 세션이 자동으로 복원됩니다. 저장하지 않고 종료했더라도 이어서 작업할 수 있습니다(아래 RECENT PROJECT 참고). 완전히 새로 시작하려면 Project ▸ New Project를 사용하세요.

처음 실행할 때 소리가 나지 않으면 Settings ▸ 오디오 장치에서 출력 장치가 현재 쓰는 장치로 지정되어 있는지 확인하세요(12장). 녹음을 하려면 입력 장치도 함께 지정합니다.

상단 Project 메뉴

New Project현재 세션을 완전히 비우고 새 프로젝트를 시작합니다(트랙과 마스터 이펙트가 모두 초기화됩니다).
Open Project…저장된 .focus 프로젝트 파일을 엽니다. 항목 위에 마우스를 올리면 최근 목록이 옆으로 펼쳐집니다(아래 참고).
Save Project현재 상태를 .focus 파일로 저장합니다. 트랙 설정, 마스터 설정, 오토메이션, 클립·테이크 정보가 함께 저장됩니다. 아직 저장한 적이 없으면 저장 위치를 묻습니다.
Save As…새 위치·새 이름으로 저장합니다. 이때 프로젝트가 소유한 오디오를 함께 모아 갑니다(아래 “프로젝트 통째로 옮기기” 참고).
Import Stem Folder…선택한 폴더 루트의 오디오 파일을 한 번에 트랙으로 등록합니다.
Import Audio Files…개별 오디오 파일을 여러 개 골라 트랙으로 추가합니다.
Load Demo Session앱에 내장된 데모 스템을 불러와 기능을 시험해 봅니다.
Clean Up Unused Recordings…저장된 프로젝트의 오디오 폴더에서 어떤 트랙도, 되돌리기 기록도 참조하지 않는 녹음·바운스 파일을 찾아 휴지통으로 보냅니다(아래 참고).
Export…믹스다운 내보내기 창을 엽니다(MP3 / WAV).

최근 프로젝트로 바로 열기

Open Project… 위에 마우스를 올리면 최근 목록이 옆으로 펼쳐집니다. 목록은 두 부분으로 나뉩니다.

RECENT PROJECT앱을 마지막으로 닫았을 때의 자동 저장 상태입니다. 저장하지 않고 종료했더라도 작업하던 세션을 그대로 이어서 열 수 있습니다.
RECENT SAVED최근에 저장한 .focus 프로젝트들입니다. 이름 아래에 실제 파일 경로가 함께 표시되어 같은 이름의 다른 프로젝트를 구분할 수 있습니다.

프로젝트 이름 설정

상단 오른쪽의 프로젝트 이름을 클릭하면 그 자리에서 이름을 고칠 수 있습니다(Enter 확정, Esc 취소). 여기서 정한 이름은 창 제목과 아래 상태 표시줄에 나타나고, 저장할 때 파일 이름의 기본값으로도 쓰입니다.

이름을 바꿔도 이미 저장된 폴더 위치는 그대로입니다. 표시 이름만 바뀌므로, 프로젝트가 모아 둔 녹음·바운스 파일과의 연결이 끊어지지 않습니다. 파일 자체를 다른 곳에 새로 만들고 싶다면 Save As…를 사용하세요.

프로젝트 통째로 옮기기 — Save As

Save As…로 저장하면 이 프로젝트가 만들어 낸 오디오(녹음 테이크, 바운스, 병합 파일)를 .focus 파일 옆의 “<프로젝트 이름> Audio” 폴더로 모아 두고, 프로젝트 안에는 상대 경로로 기록합니다. 덕분에 .focus와 그 Audio 폴더를 함께 복사하면 다른 폴더나 다른 PC에서도 그대로 열립니다.

단, 처음 불러온 스템 원본은 원래 자리에 그대로 두고 참조합니다. 스템까지 함께 옮기려면 스템 폴더도 같이 복사한 뒤, 열었을 때 NO SRC가 뜨면 같은 파일을 다시 가져와 재연결하세요(3장).

미사용 녹음 정리 — Clean Up Unused Recordings

여러 번 다시 녹음하다 보면 어느 트랙도 쓰지 않는 .wav 파일이 프로젝트 폴더에 쌓입니다. Project ▸ Clean Up Unused Recordings…는 저장된 프로젝트의 Audio 폴더를 훑어 지금 트랙에서도 쓰이지 않고 되돌리기(Undo) 기록에도 남아 있지 않은 파일만 골라내고, 파일 이름·종류·크기 목록과 총 용량을 보여 준 뒤 휴지통으로 이동합니다.

되돌리기 기록에 남아 있는 파일은 정리 대상에서 제외되므로, 방금 지운 테이크를 Undo로 되살릴 수 있습니다. 또한 삭제가 아니라 휴지통 이동이므로 실수해도 복원할 수 있습니다. 이 기능은 프로젝트를 한 번 저장한 뒤에만 쓸 수 있습니다.

2. Start & Projects

Installing and launching

Run the installer you received (FocusDAW-Studio-Setup-x.y.z.exe). It adds a FocusDAW Studio shortcut to the desktop and the Start menu — launch the app from there.

On start-up the app restores the session you last worked on, even if you closed it without saving (see RECENT PROJECT below). Use Project ▸ New Project when you want a clean slate instead.

If you hear nothing on first launch, check that the output device under Settings ▸ Audio device is the one you are actually using (ch. 12). Recording additionally needs an input device selected there.

Top "Project" Menu

New ProjectClears the session completely and starts fresh (both tracks and master effects are reset).
Open Project…Opens an existing .focus file. Hovering the item slides out a recent list (see below).
Save ProjectSaves the current state to a .focus file — track parameters, master effects, automation, and clip/take information. If the project has never been saved, you are asked where to put it.
Save As…Saves to a new name/location and gathers the audio this project owns alongside it (see "Moving a whole project" below).
Import Stem Folder…Creates a track for every audio file in the root of the chosen folder.
Import Audio Files…Adds multiple individual audio files as tracks.
Load Demo SessionLoads the demo stems bundled with the app so you can try the features.
Clean Up Unused Recordings…Scans the saved project's audio folder for recordings and bounces that no track and no undo step references, and moves them to the Recycle Bin (see below).
Export…Opens the mixdown export dialog (MP3 / WAV).

Reopening a recent project

Hovering Open Project… slides out a recent list in two parts.

RECENT PROJECTThe autosaved state from when you last closed the app — you can pick the session back up even if you never saved it.
RECENT SAVEDRecently saved .focus projects. Each entry shows its full path beneath the name so identically-named projects stay distinguishable.

Setting the Project Name

Click the project name at the top right to rename it in place (Enter confirms, Esc cancels). The name shows in the window title and the status bar, and becomes the default filename when saving.

Renaming does not move the saved folder — only the display name changes, so the project's collected recordings and bounces stay linked. Use Save As… when you actually want a new file somewhere else.

Moving a whole project — Save As

Save As… collects the audio this project produced (recorded takes, bounces, consolidated files) into a “<Project> Audio” folder next to the .focus and stores relative paths to them. Copy the .focus together with that Audio folder and the project opens correctly on another folder or another PC.

The originally imported stems are still referenced where they live. To move those too, copy the stem folder as well; if a track shows NO SRC after opening, re-import the same files to reconnect them (ch. 3).

Clean Up Unused Recordings

Re-recording repeatedly leaves .wav files in the project folder that no track uses any more. Project ▸ Clean Up Unused Recordings… scans the saved project's Audio folder for files that are neither used by a track nor held by the undo history, lists them with name, category, and size plus the total, and moves them to the Recycle Bin.

Files still referenced by the undo history are excluded, so a take you just deleted can still be brought back with Undo. And because files are moved to the Recycle Bin rather than erased, a mistake is recoverable. The command is available only after the project has been saved once.

3. 오디오 가져오기

오디오를 가져오는 방법은 세 가지입니다.

  1. Track 버튼을 눌러 파일 선택 창에서 오디오 파일을 고릅니다.
  2. Project > Import Audio Files...로 여러 파일을 선택합니다.
  3. Project > Import Stem Folder...로 스템 폴더를 선택합니다.

여러 스템을 가져오면 보컬, 드럼, 베이스, 기타, 스트링, 신스처럼 파일별로 독립 트랙이 생성됩니다. 각 트랙은 같은 시작점에 놓이지만, 실제 오디오가 없는 구간은 빈 파형으로 보이므로 편곡의 구간별 밀도를 한눈에 확인할 수 있습니다.

폴더 이름으로 프로젝트 이름 자동 설정 (v1.9.4)

아직 트랙이 없는 초기(빈) 화면에서 Import Folder로 스템 폴더를 불러오면, 그 폴더 이름이 프로젝트 이름으로 자동 설정됩니다. 스템을 폴더 단위로 정리해 둔 경우 이름을 따로 입력하지 않아도 곡 제목이 곧바로 잡혀 편리합니다.

이 자동 설정은 초기(빈) 화면에서 폴더를 불러올 때만 적용됩니다. 이미 트랙이 있거나 이름을 직접 바꿨거나 저장한 프로젝트에 폴더를 추가로 불러올 때는 기존 이름이 유지됩니다. 개별 파일(Import Files)은 자동 이름 설정 대상이 아닙니다.

드래그 앤 드롭

메인 타임라인 영역으로 오디오 파일을 끌어다 놓아도 트랙을 추가할 수 있습니다. 지원하지 않는 확장자는 자동으로 무시됩니다.

프로젝트를 다시 열 때

.focus 프로젝트는 오디오 설정과 파일 경로를 저장합니다. 원본 오디오 파일이 옮겨지거나 지워지면 트랙 헤더에 붉은 NO SRC 표시가 나타납니다. 이때는 같은 파일을 그 트랙 위로 끌어다 놓거나 같은 이름의 오디오를 다시 가져오면 누락된 트랙이 재연결됩니다.

3. Importing Audio

There are three ways to import audio files into your session:

  1. Click the + Track button to choose files via the file selector.
  2. Select Project > Import Audio Files... from the menu bar to import multiple files.
  3. Select Project > Import Stem Folder... to batch import all stems inside a folder.

Importing multiple stems creates separate, independent tracks for Vocals, Drums, Bass, Guitar, and so on. Tracks are aligned to the same starting point. Sections where a track is silent are shown as flat line waveforms, providing a clear layout of the arrangement density.

Auto-Naming the Project from the Folder (v1.9.4)

When you use Import Folder on the initial (empty) screen — before any track exists — the folder's name automatically becomes the project name. If you keep your stems in per-song folders, the title is set instantly without typing.

This auto-naming applies only when importing a folder onto the empty start screen. If the project already has tracks, was renamed, or was saved, importing another folder keeps the existing name. Individual files (Import Files) are not auto-named.

Drag and Drop

You can drag and drop audio files directly from your system file explorer onto the main timeline area to add new tracks. Unsupported formats are ignored automatically.

Reconnecting Missing Audio

The .focus file references audio file paths. If the original audio is moved or deleted, the track header shows a red NO SRC chip. Drop the same file onto that track, or re-import audio with matching names, to reconnect it.

4. 오디오 녹음 · 클립 편집

FocusDAW Studio는 마이크·오디오 인터페이스로 들어오는 입력 신호를 Audio In 트랙에 실시간으로 녹음할 수 있습니다. 녹음 결과는 프로젝트 폴더에 .wav 파일(테이크)로 저장되고, 다른 스템 트랙과 똑같이 볼륨·팬·솔로·뮤트·오토메이션·마스터 이펙트를 적용할 수 있습니다. 기존 스템 위에 보컬이나 애드리브를 덧입히는 오버더빙이 이 앱의 핵심 작업입니다.

이 장은 녹음 → 여러 테이크 중 고르기 → 클립 다듬기 → 보컬 이펙트 걸기까지의 흐름을 순서대로 다룹니다.

녹음을 시작하기 전에 먼저 Settings ▸ Audio Devices에서 입력 장치(모드·입력/출력 장치·샘플레이트·버퍼)를 지정해야 합니다. 장치 설정 방법은 12. 설정 · 오디오 장치 · 테마를 참고하세요.

① Audio In 트랙 만들기

타임라인 왼쪽 위 TRACK 영역에 추가 버튼이 두 개 있습니다. +(플러스)는 오디오 파일을 불러오는 일반 파일 트랙을, + Audio In 버튼은 입력 녹음용 트랙을 만듭니다. Audio In 트랙은 파일 트랙과 구분되도록 헤더에 파란 틴트가 적용되며, 파일 트랙 그룹(FILE TRACKS) 바깥에 놓입니다.

② Audio In 트랙 헤더 컨트롤

Audio In 트랙 헤더에는 일반 트랙의 볼륨·팬·솔로·뮤트에 더해, 녹음을 위한 전용 컨트롤이 있습니다. (트랙 크기가 S일 때는 공간이 좁아 ARM만 제목 행에 인라인으로 표시되고, M/L에서 모든 컨트롤이 펼쳐집니다.)

ARM이 트랙을 녹음 대기(무장) 상태로 만듭니다. 녹음은 ARM된 트랙에만 기록되며, 한 번에 하나의 Audio In 트랙만 ARM됩니다(다른 트랙을 ARM하면 이전 트랙은 자동 해제). ARM된 트랙이 있어야 상단의 Record 버튼이 활성화됩니다.
입력 포트 선택이 트랙이 받을 입력 채널을 고릅니다. 현재 열린 인터페이스의 실제 채널 수에 맞춰 모노 포트(Input 1, Input 2 …)와 연속 스테레오 쌍(Input 1-2 …)이 동적으로 나열됩니다. (ASIO는 인터페이스가 제공하는 실제 채널 이름을 그대로 표시합니다.)
MON입력 모니터링. 켜면 입력 신호를 출력으로 흘려보내 지금 들어오는 소리를 실시간으로 들을 수 있습니다. 모노 입력은 양쪽 채널로 센터링되어 재생됩니다.
LIM입력 리미터(천장 −1.0 dBFS). 켜져 있으면 과입력으로 인한 클리핑을 방지합니다. 기본값은 켜짐입니다. 리미터가 실제로 신호를 누른 양은 입력 게인 슬라이더의 게인 리덕션(GR) 미터(레벨 미터 아래의 붉은 막대, 오른쪽에서 채워짐)로 확인합니다. GR이 크게 자주 움직이면 입력 게인이 너무 큰 것이므로 낮춰 주세요.
입력 게인녹음될 입력 신호의 게인을 조절합니다. 헤더에 현재 게인이 dB로 표시됩니다. 너무 크면 왜곡, 너무 작으면 잡음이 커지므로 미터가 상단에 닿지 않는 선에서 맞춥니다.
볼륨 · 팬파일 트랙과 동일하게 재생 레벨과 스테레오 위치를 조절합니다(볼륨은 −∞ ~ +6 dB).

헤더 아래쪽 줄에는 오토메이션 AUTO 버튼 옆에 파형 모양의 FX 버튼이 있습니다. 이 버튼이 보컬 채널 스트립 창을 여는 입구입니다(⑨ 참고). 오른쪽 SOURCE 칩은 이 트랙의 원본 오디오가 정상적으로 연결돼 있음을 뜻하며, 파일을 찾지 못하면 붉은 NO SRC로 바뀝니다.

③ 녹음 준비 — ARM

녹음할 트랙의 ARM 버튼을 눌러 녹음 대기(무장) 상태로 만듭니다. ARM된 트랙이 있어야 트랜스포트의 Record 버튼이 활성화되고, 녹음은 오직 그 트랙에만 기록됩니다.

④ 녹음 시작 — 트랜스포트 규칙

ARM한 뒤 트랜스포트의 Record(빨간 점) 버튼을 누르면 녹음이 시작됩니다. 실수를 막기 위해 녹음 트랜스포트는 다음 규칙을 따릅니다.

정지 상태에서 Record — 프리롤(기본)프리롤이 켜져 있고 앞에 들을 음악이 있으면, 재생 위치보다 설정한 초만큼 앞에서 기존 음악이 먼저 재생되고 원래 위치에 도달하면 녹음이 시작됩니다. 화면 상단에 PRE-ROLL 표시와 남은 시간이 뜨며, 타임라인은 가려지지 않습니다.
정지 상태에서 Record — 카운트인프리롤이 꺼져 있거나, 들을 음악이 없을 때(빈 프로젝트 / 맨 앞에서 녹음)는 화면 중앙에 카운트인 오버레이가 뜬 뒤 재생과 녹음이 동시에 시작됩니다. 메트로놈이 켜져 있으면 4 → 3 → 2 → 1(프로젝트 BPM 기준 한 마디), 꺼져 있으면 3 → 2 → 1(1초 간격 무음)입니다.
재생 중 Record카운트인 없이 즉시 녹음이 시작됩니다.
프리롤 길이트랜스포트의 프리롤 버튼을 누를 때마다 2초 → 4초 → 8초 → 끔 으로 바뀝니다(버튼에 현재 초가 표시됨, 기본 4초). 느린 곡은 길게, 빠른 곡은 짧게 두면 편합니다.
왜 프리롤인가이 앱은 불러온 스템 위에 덧녹음하는 도구입니다. 그런 음악은 중간에 템포가 미묘하게 흔들리고, BPM이 맞아도 클릭이 곡의 박자 위상까지 알 수는 없어서 합성 클릭은 음악과 어긋나기 쉽습니다. 프리롤의 리드인은 곡 자체이므로 정의상 박자가 맞습니다. 길이를 마디가 아니라 초로 정하는 것도 같은 이유입니다.
메트로놈(카운트인 클릭)트랜스포트의 메트로놈 버튼으로 켜고 끕니다. 카운트인으로 시작할 때만 쓰입니다(프리롤에는 클릭이 없습니다 — 위 "왜 프리롤인가" 참고). 켜면 프로젝트 BPM에 맞춘 4박 클릭이 울립니다(첫 박은 높은 음으로 강조). 클릭은 모니터 출력 전용이라 녹음 파일과 Export에는 들어가지 않으며, 녹음이 시작되면 멈춥니다. 프로젝트 BPM이 없으면 버튼이 비활성됩니다.
Repeat 자동 해제Record를 누르면 반복(Loop)이 자동으로 꺼집니다. 녹음이 끝나면 이전 반복 상태로 복원됩니다.
자동 종료재생이 기존 트랙 중 가장 긴 트랙의 끝에 도달하면 녹음과 재생이 자동으로 멈춥니다. 기존 트랙이 없으면 직접 Stop을 누를 때까지 계속 녹음합니다.
녹음 중 Record / Stop녹음과 재생을 모두 정지합니다. 트랜스포트는 0초로 복귀합니다.
녹음 중 Play/Pause · 처음으로 이동녹음 중에는 무시됩니다. 녹음을 멈추려면 Record 또는 Stop을 사용하세요.
프리롤 · 카운트인 도중 조작진행 중에 Record / Stop / Play를 누르면 취소됩니다(메트로놈 클릭도 즉시 멈춤). 프리롤을 취소하면 재생이 멈추고 플레이헤드가 Record를 누른 위치로 되돌아갑니다.
프리롤이 안 되는 경우① Repeat 구간이 켜져 있으면 프리롤 대신 카운트인이 쓰입니다(구간 반복은 플레이헤드를 구간 안에 가두므로 앞으로 되감을 수 없습니다). ② 재생 위치가 곡 맨 앞이거나 다른 트랙에 음악이 없으면 들려줄 리드인이 없으므로 카운트인으로 넘어갑니다.
녹음·카운트인 중에는 키보드 이동키(←/→/,/./0)와 타임라인·눈금자 마우스 클릭 이동(seek)이 모두 차단됩니다. 녹음 중 실수로 플레이헤드가 튀는 것을 막기 위한 것으로, 위치를 바꾸려면 먼저 녹음을 멈추세요.

⑤ 구간 반복 녹음 — 테이크 쌓기

같은 구절을 여러 번 불러 그중 제일 좋은 것을 고르고 싶을 때 씁니다. 타임라인 아래 OUTPUT FX 눈금 레인을 드래그해 Repeat 구간을 만들고 Repeat를 켠 뒤 Record를 누르면, 구간을 한 바퀴 돌 때마다 테이크가 하나씩 쌓입니다. 녹음 중에는 REC Take A · B · C … 배지가 현재 몇 번째 테이크인지 알려 줍니다.

⑥ 테이크 고르기와 컴프(Comp)

테이크가 둘 이상 쌓이면 클립 왼쪽 위에 “▾ n takes” 배지가 생깁니다. 이 배지를 누르면 아래로 테이크 레인이 펼쳐져 Take A, B, C … 를 나란히 볼 수 있습니다.

테이크는 클립(녹음한 구간)별로 따로 관리됩니다. 한 트랙에서 서로 다른 구간을 여러 번 녹음했다면, 레인 목록도 CLIP 1 · CLIP 2 · CLIP 3 … 머리글로 나뉘어 표시되고 각 클립의 테이크는 그 클립 안에서 Take A부터 번호가 매겨집니다. 배지도 “3 clips · 8 takes”처럼 알려 줍니다. 클립마다 테이크 개수가 달라도 서로 영향을 주지 않으며, 선택한 테이크가 맨 위 메인 타임라인에 표시되고 재생·내보내기에 쓰입니다.

테이크 고르기레인을 클릭하면 그 클립이 해당 테이크로 재생됩니다. 다른 클립의 선택은 그대로 유지됩니다(예: 1번 클립은 Take A, 2번 클립은 Take C, 3번 클립은 Take B).
컴프 만들기 (swipe)레인 위를 가로로 쓸면(swipe) 한 클립 안에서도 구간마다 다른 테이크를 골라 이어 붙일 수 있습니다. “앞부분은 Take B, 뒷부분은 Take D”처럼 좋은 부분만 조합하는 방식입니다. 쓸기는 그 테이크가 속한 클립 구간 안으로만 적용됩니다.
Clear쓸어서 나눈 구간을 지우고 각 클립이 다시 테이크 하나를 통째로 재생하게 되돌립니다. 클립별 테이크 선택은 그대로 남습니다.
테이크 삭제각 레인 오른쪽의 × 버튼으로 그 테이크를 지웁니다.
Flatten Comp조합한 결과를 하나의 오디오 파일로 확정합니다. 클립마다 선택한 테이크가 각각 확정되고 나머지 테이크는 정리됩니다. 모든 테이크의 파형이 완전히 로드된 뒤에 실행하세요.
레인 접기배지를 다시 누르거나 아래쪽 ∨ 버튼으로 레인을 접습니다.
테이크 배지를 눌러도 재생 위치는 움직이지 않습니다. 배지는 레인을 펼치고 접는 역할만 합니다.

⑦ Punch 녹음 — 일부 구간만 다시 부르기

한 소절만 틀렸을 때 전체를 다시 부르지 않고 그 구간만 덮어쓰는 방식입니다. 먼저 Repeat 구간을 만든 다음 트랜스포트의 Punch 버튼을 켜고 Record를 누르면, 프리롤로 들어가 구간 시작점에서 자동으로 녹음이 시작(punch-in)되고 끝점에서 자동으로 멈춥니다(punch-out). 구간 바깥의 소리는 건드리지 않습니다.

Punch 켜기 조건Repeat 구간이 있어야 버튼이 활성화됩니다. 구간을 지우면 Punch도 자동으로 꺼집니다(구간 없는 상태에서 전체가 덮어써지는 사고를 막기 위함).

원본 보존펀치 전의 소리는 버려지지 않고 테이크로 남습니다. 마음에 들지 않으면 이전 테이크로 되돌릴 수 있습니다.

프리셋은 Noise Gate를 일부러 건드리지 않습니다. 적정 임계값은 녹음마다 노이즈 바닥이 달라 고정값이 의미가 없기 때문입니다 — 너무 낮으면 아무 일도 일어나지 않고, 너무 높으면 말끝이 잘립니다. 게이트는 자신의 녹음을 들으며 직접 맞추세요.

⑩ 노이즈 제거 — Broadband De-noise

에어컨 소리나 히스처럼 계속 깔려 있는 잡음을 없애는 기능입니다. 먼저 잡음만 있는 구간을 들려주어 “이것이 잡음”이라고 학습시킨 뒤, 그 특성을 곡 전체에서 빼내는 방식입니다.

  1. 해당 트랙에서 소리 없이 잡음만 있는 구간(숨소리·방 소음만 있는 곳)을 Repeat 구간으로 지정합니다.
  2. 스트립의 Learn Noise를 누릅니다. 학습에 성공하면 버튼이 ✓ Noise learned로 바뀌고 아래에 학습한 길이가 표시됩니다.
  3. AMOUNT로 제거 강도를 정한 뒤 Apply De-noise를 누릅니다.
De-noise는 비파괴입니다. 처리 결과는 새 파일로 저장되고 원본 녹음 WAV는 그대로 남으며, 되돌리기(Undo)도 됩니다. AMOUNT를 지나치게 올리면 목소리까지 깎여 답답해질 수 있으니, 조금씩 올리며 들어 보고 정하세요.

4. Recording & Clip Editing

FocusDAW Studio can record a live input signal from a microphone or audio interface straight onto an Audio In track. Each recording is saved into the project folder as a .wav take and behaves exactly like any other stem — volume, pan, solo, mute, automation, and the master effects all apply. Overdubbing vocals or ad-libs on top of imported stems is what this app is built around.

This chapter follows the whole flow in order: record → choose among takes → tidy the clips → shape the voice.

Before recording, set up your input under Settings ▸ Audio Devices (mode, input/output device, sample rate, buffer). See 12. Settings, Audio Devices & Themes for the full device setup.

1. Create an Audio In track

The TRACK area at the top left of the timeline has two add buttons. The + (plus) creates a normal file track for importing audio; the + Audio In button creates an input-recording track. Audio In tracks are tinted blue in the header and sit outside the FILE TRACKS group.

2. Audio In track header controls

In addition to the usual volume, pan, solo, and mute, an Audio In track header adds dedicated recording controls. (At track size S only ARM is shown inline on the title row for space; M/L reveal every control.)

ARMArms this track for recording. Audio is only captured to the armed track, and only one Audio In track can be armed at a time (arming another disarms the previous one). The transport Record button is only active while a track is armed.
Input portChooses which input channel this track receives. Ports are built dynamically from the real channel count of the currently open interface: mono ports (Input 1, Input 2 …) and consecutive stereo pairs (Input 1-2 …). (ASIO shows the interface's actual channel names.)
MONInput monitoring. When on, the incoming signal is passed to the output so you can hear it live. A mono input is centered to both output channels.
LIMInput limiter (ceiling −1.0 dBFS). When on, it prevents clipping from a hot input. On by default. How much the limiter is actually clamping is shown by the gain-reduction (GR) meter on the input gain slider (the red bar beneath the level meter, filling from the right). If GR moves a lot and often, the input gain is too high — turn it down.
Input gainSets the gain of the signal being recorded; the header shows the current gain in dB. Aim for a level where the meter does not hit the top — too hot distorts, too low raises the noise floor.
Volume · PanPlayback level and stereo position, same as a file track (volume ranges −∞ to +6 dB).

On the lower row, next to the automation AUTO button, sits a waveform-shaped FX button — this is the entry point to the Vocal Channel Strip (see step 9). The SOURCE chip on the right confirms the track's audio is linked; it turns into a red NO SRC chip if the file cannot be found.

3. Arming the track

Press ARM on the track you want to record. The transport Record button only becomes active while a track is armed, and audio is captured to that track alone.

4. Starting a take — transport rules

Once armed, press the transport Record (red dot) button to start recording. To prevent mistakes, the recording transport follows these rules:

Record from stopped — pre-roll (default)With pre-roll on and music to roll into, playback starts the set number of seconds before the playhead and recording begins when it reaches the original position. A PRE-ROLL chip and the remaining time appear at the top; the timeline stays visible.
Record from stopped — count-inWith pre-roll off, or when there is nothing to roll into (empty project / recording at the very start), a count-in overlay appears and playback and recording start together. With the metronome on it counts 4 → 3 → 2 → 1 (one bar at the project BPM); with it off, 3 → 2 → 1 silently, a second apart.
Record while playingRecording begins immediately, with no count-in.
Pre-roll lengthEach press of the pre-roll button cycles 2s → 4s → 8s → off (the button shows the current length; default 4s). Longer suits slow songs, shorter suits fast ones.
Why pre-rollThis app records over imported stems. That material tends to drift in tempo, and even at a matching BPM a click cannot know the song's beat phase — so a synthesized click easily disagrees with the music. A pre-roll's lead-in is the song, so it is in time by definition. That is also why the length is set in seconds rather than bars.
Metronome (count-in click)Toggled with the metronome button in the transport. Used only when starting with a count-in (pre-roll has no click — see "Why pre-roll"). When on, it plays four clicks on the project's BPM (the downbeat is accented). The click is monitor-only — it is never in the recorded file or an Export — and it stops once recording starts. Without a project BPM the button is disabled.
Repeat auto-offPressing Record turns Loop off automatically, and restores the previous loop state when recording ends.
Auto-stopWhen playback reaches the end of the longest existing track, recording and playback stop automatically. With no existing tracks, recording continues until you press Stop.
Record / Stop while recordingStops both recording and playback; the transport returns to 0.
Play/Pause · Return-to-start while recordingIgnored during recording. Use Record or Stop to end the take.
During pre-roll / the count-inPressing Record / Stop / Play cancels it (and silences the click immediately). Cancelling a pre-roll stops playback and returns the playhead to where you pressed Record.
When pre-roll does not apply① With a Repeat region active, the count-in is used instead — a repeat region keeps the playhead inside itself, so there is nowhere to roll back to. ② At the very start of the song, or with no music on other tracks, there is no lead-in to play, so it falls back to the count-in.
During recording and the count-in, the keyboard seek keys (←/→/,/./0) and mouse-click seeking on the timeline/ruler are all blocked to keep the playhead from jumping mid-take. Stop recording first if you need to move the position.

5. Loop recording — stacking takes

Use this when you want to sing a phrase several times and keep the best one. Drag a Repeat region on the OUTPUT FX ruler lane, turn Repeat on, and press Record: each pass around the region records a new take. While recording, a REC Take A · B · C … badge shows which take is being captured.

6. Choosing takes and comping

Once more than one take exists, a “▾ n takes” badge appears at the top left of the clip. Click it to expand the take lanes and see Take A, B, C … side by side.

Takes belong to the clip they were recorded into. If you recorded several different spots on one track, the lane list is split by CLIP 1 · CLIP 2 · CLIP 3 … headers and each clip numbers its own takes from Take A (the badge reads e.g. “3 clips · 8 takes”). Clips can hold different numbers of takes without affecting each other, and the take you select is what the main lane shows and what plays and exports.

Pick a takeClick a lane to play that take for that clip. The other clips keep their own selections — clip 1 on Take A, clip 2 on Take C, clip 3 on Take B is perfectly fine.
Build a comp (swipe)Swipe horizontally across a lane to assemble one clip from different passes — "Take B for the first half, Take D for the rest". A swipe only applies inside its own clip's span.
ClearDrops the swiped regions so each clip plays one whole take again. The per-clip take selections stay.
Delete a takeThe × button at the right of each lane removes that take.
Flatten CompCommits the comp to audio. Every clip's selected take is committed and the remaining takes are cleared away. Run it once every take shows a fully loaded waveform.
Collapse lanesClick the badge again, or the ∨ button below the lanes.
Clicking the take badge does not move the playhead — it only opens and closes the lanes.

7. Punch recording — redoing part of a take

When only one phrase is wrong, punch lets you overwrite just that span instead of re-singing everything. Set a Repeat region, turn on the transport's Punch button, and press Record: playback pre-rolls in, recording punches in automatically at the region start and punches out at its end. Everything outside the region is untouched.

Requires a regionThe button is enabled only while a Repeat region exists. Removing the region turns Punch off automatically — this prevents a region-less punch from destructively re-recording the whole track.
Punch on + Repeat offSingle punch — records the region once and replaces that part of the active take.
Punch on + Repeat onLoop-Punch Comp — loops the region and stores every pass as a region-scoped take, so you can pick the best one from the take lanes.
The original is keptWhat was there before the punch is kept as a take, so you can always go back to it.

9. The Vocal Channel Strip (FX)

The FX button (waveform icon) on an Audio In or Bounce track header opens the Vocal Channel Strip window. Six modules for shaping a recorded voice are stacked in the order the signal passes through them. The strip is an insert applied before the track fader (pre-fader) and is reflected in playback, Export, and the saved project.

STRIP ACTIVE (A/B)Bypasses or engages the whole strip — flip it to compare processed against unprocessed on the spot.
PRESETFour vocal starting points — Clean Lead · Warm Pop · Bright Air · Podcast — which set the HPF, EQ, compressor, and de-esser together.
ResetReturns every module to its defaults and switches it off. It deliberately leaves the A/B (bypass) state alone, so resetting never silently changes what you are hearing.
SpectrumOverlays the frequency curve before (PRE) and after (POST) the chain. Move the EQ and the POST curve follows in real time, so you can see how the voice is being reshaped.
01 High-Pass FilterCuts low-end rumble and plosives (12 dB/oct). FREQ sets the cutoff.
02 Noise GateAttenuates anything below the threshold to clean up breaths and room tone. RATIO · ATTACK · RELEASE shape the response, and the ATTENUATION meter shows how much is being removed right now.
03 EqualizerA 9-band graphic EQ — drag the vertical faders to boost or cut each band (double-click = 0 dB).
04 CompressorNarrows the gap between loud and quiet for an even vocal. THRESH · RATIO · ATTACK · RELEASE · MAKEUP knobs respond to the wheel for fine-tuning and double-click to recentre. The GAIN REDUCTION meter shows how hard it is working.
05 De-EsserTames harsh sibilance ("s"/"sh") by attenuating just that band when it gets loud — applied after the compressor. Set FREQ · THRESH · AMOUNT and watch the DE-ESS GR meter.
06 Broadband De-noiseRemoves steady room tone or hiss (see step 10). This one is an offline print, not a realtime effect.

Each module has its own ON / OFF button. Even while off, touching a knob switches that module on automatically.

The presets deliberately leave the Noise Gate alone. A usable threshold depends on your own recording's noise floor, so a fixed value is meaningless — too low and nothing happens, too high and word endings get chopped. Set the gate by ear on your own take.

10. Broadband De-noise

This removes constant background noise such as air conditioning or hiss. You first let it learn what the noise sounds like from a silent stretch, then subtract that profile from the whole clip.

  1. Mark a stretch of this track that contains only noise (breaths / room tone, no singing) as the Repeat region.
  2. Press Learn Noise in the strip. On success the button becomes ✓ Noise learned and the learned length is reported below.
  3. Set AMOUNT, then press Apply De-noise.
De-noise is non-destructive: the cleaned audio is printed to a new file, the original recording WAV is kept, and the whole operation is undoable. Pushing AMOUNT too high starts eating the voice itself and sounds dull — raise it gradually and listen.

11. Managing takes & renaming

  • When recording ends, the captured signal appears as a waveform and the audio is saved as a .wav file. If you started partway through the song, the clip is placed at that position.
  • Recording again on the same track creates a new take. Without Repeat or Punch, the latest take is the one that plays.
  • Double-click a track title to rename it inline (Enter to confirm, Esc to cancel). Track names and recording file names are handled separately, so renaming a track does not rename its already-recorded files.
Like any other audio, recordings are shaped by the master EQ, reverb, echo, and other output effects, plus track volume automation. Finished takes are rendered into the full mix in 11. Exporting Mixdown.

6. BPM 표시 및 설정

FocusDAW Studio는 트랙 오디오에서 곡의 BPM(분당 박자 수)을 자동으로 측정하고, 그 값을 기준으로 전체 음악의 재생 템포를 조정할 수 있습니다. 새 프로젝트의 BPM은 처음에 ---로 표시되며, 모든 트랙을 지우거나 새 프로젝트를 시작하면 다시 ---로 초기화됩니다.

BPM 표시기 오른쪽에는 Vari BPM 스위치가 있습니다. 이 스위치를 켜야 재생 BPM으로 곡 속도를 조정하며, 끄면 재생 BPM을 바꿔도 속도가 변하지 않습니다(기본값 OFF). 스위치를 켠 상태에서 BPM 표시기 위에 마우스 휠을 돌리거나 ▲▼ 버튼을 누르면 뒤쪽 재생 BPM이 1씩 바뀌고, 곡 전체가 그 비율(재생 BPM ÷ 프로젝트 BPM)만큼 빨라지거나 느려집니다.

Vari BPM은 프로젝트 BPM이 정해진 뒤에만 켤 수 있습니다. 기준이 될 BPM이 없으면 속도 비율을 계산할 수 없기 때문입니다. BPM 표시기가 ---인 상태에서 스위치를 누르면 스위치가 흐리게 표시된 채 BPM 측정이 필요하다는 안내창이 뜹니다. 아래 ①~④ 절차로 BPM을 먼저 정하세요.

① BPM 측정 대상 트랙 선택 (B 버튼)

먼저 어떤 트랙의 오디오로 BPM을 측정할지 정합니다. 트랙 헤더의 B 버튼을 누르면 그 트랙이 BPM 측정 소스로 선택되어 배경이 채워지며, B는 한 번에 한 트랙에만 켜집니다. 드럼처럼 박자가 뚜렷한 트랙을 고르면 측정이 더 정확합니다.

② BPM 설정 패널 열기

BPM 표시기를 클릭하면 아래로 설정 패널이 펼쳐집니다. 다시 누르거나, 마우스가 패널 밖으로 나간 채 5초가 지나면 접힙니다.

DetectB로 선택한 트랙의 오디오를 분석해 BPM을 자동 추정합니다. 추정값이 아래 입력칸에 채워집니다.
직접 입력입력칸에 BPM 숫자를 직접 적을 수 있습니다.
TAP음악을 들으며 박자에 맞춰 버튼을 반복해 누르면 BPM을 수동 측정합니다. 누를수록 값이 정확해지고, 버튼에는 실시간 BPM과 탭 횟수(TAP · n)가 표시됩니다.
APPLY측정/입력한 값을 프로젝트 BPM과 재생 BPM에 모두 적용합니다.

자동 감지가 잘 맞지 않을 때는 TAP이 가장 확실합니다. 음악을 재생해 두고 박자에 맞춰 TAP 버튼을 반복해 누르면, 누른 간격의 평균으로 BPM이 계산됩니다. 버튼에는 지금까지의 추정값과 누른 횟수가 TAP · n 형태로 표시되며, 여러 번 누를수록 값이 안정됩니다.

③ Detect 분석 중 표시

Detect를 누르면 분석이 진행되는 동안 버튼이 회전 아이콘과 Analyzing… 표시로 바뀝니다. 분석이 끝나면 추정된 BPM이 입력칸에 강조 효과와 함께 표시됩니다.

④ 전체 음악 템포 바꿔 재생하기

Vari BPM 스위치를 켠 뒤 재생 BPM(뒤 숫자)을 바꾸면 모든 트랙이 같은 비율로 빨라지거나 느려진 상태로 재생됩니다. 예를 들어 프로젝트 BPM이 100일 때 재생 BPM을 120으로 올리면 곡 전체가 1.2배 빠르게 재생됩니다.

실시간 재생의 템포 변경은 Vari BPM이 켜져 있을 때 캐시형 Time Stretch 프리뷰를 준비해 피치 보존을 우선 적용합니다. Export 창의 Keep pitch 옵션은 Electron 데스크톱 Export에서 검증된 단기 안정 Time Stretch 경로를 사용해 파일 출력에 피치 보존을 적용합니다.

6. BPM Display & Settings

FocusDAW Studio detects a song's BPM (beats per minute) from a track's audio and lets you adjust the playback tempo of the whole song based on it. A new project starts with BPM shown as ---, and it returns to --- whenever you clear all tracks or start a new project.

The Vari BPM switch to the right of the indicator must be on for the playback BPM to change the song speed (off = no speed change; default off). With it on, hover the BPM indicator and scroll the mouse wheel, or use the ▲▼ buttons, to change the playback BPM by 1 — the whole song speeds up or slows down by that ratio (playback BPM ÷ project BPM).

Vari BPM can only be switched on once a project BPM exists — without a reference tempo there is no ratio to apply. While the indicator reads --- the switch is dimmed, and clicking it opens a notice explaining that the BPM has to be measured first. Use steps 1–4 below to set one.

1. Choose the detection source track (B button)

Press the B button on a track header to mark it as the BPM detection source (its background fills in). Only one track can be the B source at a time. Picking a track with a clear beat (e.g. drums) gives more accurate detection.

2. Open the BPM settings panel

Click the BPM indicator to expand the settings panel. Click it again, or leave it inactive outside the mouse area for 5 seconds, to collapse it.

DetectAnalyzes the B-selected track's audio and estimates its BPM, filling the input field.
Manual inputType a BPM value directly into the field.
TAPTap along with the beat repeatedly to measure BPM. Accuracy improves the more you tap, and the button shows a live BPM and tap count (TAP · n).
APPLYApplies the measured/entered value to both the project BPM and the playback BPM.

When automatic detection struggles, TAP is the most reliable route. Play the song and tap the button along with the beat — the BPM is averaged from your tap intervals. The button shows the running estimate and tap count as TAP · n, and the value settles the more you tap.

3. Detection-in-progress feedback

While Detect runs, the button changes to a spinner with Analyzing…. When it finishes, the estimated BPM appears in the input field with a brief highlight.

4. Play back at a changed tempo

With the Vari BPM switch on, changing the playback BPM (the back number) plays every track faster or slower by the same ratio. For example, with a project BPM of 100, raising the playback BPM to 120 plays the whole song 1.2× faster.

Realtime tempo changes prepare a cached Time Stretch preview when Vari BPM is enabled, prioritizing pitch preservation during playback. The Export dialog's Keep pitch option applies pitch preservation through the validated short-term stable Time Stretch path for Electron desktop exports.

7. Key 표시 및 설정

FocusDAW Studio는 프로젝트에 로드된 트랙 오디오의 화성 성분을 종합적으로 분석하여 곡의 원곡 키(Key)를 자동으로 감지하고, 반음(Semitones) 단위로 곡의 조성을 올리거나 내려서 실시간으로 이조 재생할 수 있습니다. 처음 세션을 열었을 때 키 표시창은 ---로 표시됩니다.

① Key 설정 패널 열기

Key 표시창 부분을 클릭하면 아래로 Key 설정 패널이 펼쳐집니다. 이 패널은 클릭하여 켜고 끌 수 있으며, 마우스 포인터가 패널에서 벗어난 지 5초가 지나면 자동으로 닫힙니다.

② Key Detection (조성 감지)

패널 내의 Detect 버튼을 누르면 프로젝트의 활성화된 모든 오디오 트랙을 정밀 분석(STFT 기반 크로마 연산)하여 원곡의 키를 추정합니다. 결과는 하나의 원곡 Key이며, 패널 가운데의 원Key 표시창에 나타나고 하단 조성 목록에서도 강조 표시됩니다.

③ Key 설정 적용

원하는 키 후보를 선택하거나, 패널 내의 + / - 버튼을 클릭해 원하는 반음(Semitones, 최대 ±6) 오프셋을 설정한 뒤 APPLY 버튼을 누르면 프로젝트의 기준 키가 세션에 등록됩니다.

④ 실시간 이조 재생 (Vari Key)

Key 표시기 오른쪽의 Vari Key 스위치를 켜면, 사용자가 변경한 조(Key)의 피치가 재생 엔진에 즉각 반영되어 음높이가 실시간으로 변조(Pitch Shift)되어 플레이됩니다. 스위치를 끄면 원래 녹음된 피치 그대로 재생됩니다.

Vari BPM과 Vari Key 동시 적용 시 주의
Vari BPM과 Vari Key를 모두 켜서 템포와 음높이를 동시에 크게 조절하는 경우, 실시간 타임 스트레칭 및 피치 변조 처리가 겹치게 됩니다. 이로 인해 연산 부하가 증가하거나 재생 오디오에 과도한 소리 왜곡(Artifact)이 생길 수 있으므로, 적절한 범위 안에서 조절하는 것을 권장합니다.

7. Key Display & Settings

FocusDAW Studio analyzes the harmonic content of all loaded audio tracks to estimate the song's original key and lets you shift the pitch up or down in semitones (up to ±6 semitones) for real-time key-shifted playback. When a new session is opened, the Key indicator reads ---.

1. Open Key Settings Panel

Click the Key indicator in the toolbar to expand the Key settings panel. You can toggle the panel open and closed by clicking it, and it will close automatically 5 seconds after the mouse pointer leaves the panel area.

2. Key Detection

Click the Detect button in the panel to run a comprehensive harmonic analysis (STFT-based chromagram) across all active audio tracks. It produces one original key, shown in the original-key box in the middle of the panel and highlighted in the key list below it.

3. Applying Key Settings

Select your preferred candidate key, or use the + / - buttons to adjust the semitones offset (up to ±6 semitones), then click APPLY to write the reference key to the project.

4. Real-time Pitch Shifting (Vari Key)

Enable the Vari Key switch next to the Key indicator to apply your pitch shifts directly to the playback engine in real-time. Turning the switch off reverts the playback pitch back to the original recorded audio state.

Caution when combining Vari BPM and Vari Key
If both Vari BPM and Vari Key are enabled to make significant changes to both tempo and pitch at the same time, the combined real-time time-stretching and pitch-shifting processing will run concurrently. This can increase CPU overhead or cause audibly noticeable sound artifacts, so we recommend keeping adjustments within moderate ranges.

8. 볼륨 오토메이션

트랙 헤더의 VOL AUTO를 켜면 트랙 위에 볼륨 오토메이션 곡선이 표시됩니다. 곡선의 점은 시간에 따른 볼륨 변화를 의미합니다.

  • 오토메이션 선을 클릭하면 새 포인트가 추가됩니다.
  • 포인트를 드래그하면 시간과 볼륨 값을 바꿀 수 있습니다.
  • 중간 포인트를 우클릭하면 삭제됩니다. 시작점과 끝점은 유지됩니다.
  • 트랙 크기를 L로 키우면 Reset과 Curve 버튼을 함께 볼 수 있습니다.
  • Curve를 켜면 직선 연결 대신 부드러운 곡선으로 볼륨 변화를 적용합니다.

오토메이션 편집 방법

마우스 왼쪽 버튼 클릭오토메이션 선 위를 클릭하면 새 편집점이 추가됩니다.
편집점 드래그편집점 위에 마우스를 올리면 손 모양 커서로 바뀝니다. 그 상태에서 마우스 왼쪽 버튼을 누른 채 움직이면 편집점의 시간 위치와 볼륨 값을 이동할 수 있습니다.
마우스 오른쪽 버튼 클릭편집점 위에 마우스를 올려 손 모양 커서가 보이는 상태에서 오른쪽 마우스 버튼을 누르면 해당 편집점이 삭제됩니다. 시작점과 끝점은 삭제되지 않습니다.

포인트 조정

오토메이션 선 위를 클릭해 포인트를 추가하고, 포인트를 드래그해 볼륨 변화 시점과 크기를 조절합니다. 아래로 내린 구간은 소리가 작아지고, 위로 올린 구간은 원래 볼륨에 가깝게 재생됩니다.

Curve 적용

Curve를 켜면 포인트 사이가 직선이 아니라 부드러운 곡선으로 이어집니다. 급격한 볼륨 변화보다 자연스러운 페이드나 강조를 만들 때 유용합니다.

8. Volume Automation

Toggling VOL AUTO in the track header displays a yellow automation lane over the track lane. Points on this line represent volume changes over time.

  • Left-click the line to add a new automation point.
  • Click and drag points horizontally (time) and vertically (volume).
  • Right-click a point to delete it. The start and end anchors cannot be deleted.
  • When track size is set to L, Reset and Curve buttons appear.
  • Toggling Curve connects points with smooth bezier curves instead of linear lines.

How to Edit Automation Points

Left-click lineCreates a new automation point at the cursor position.
Drag pointHover over a point to see a hand cursor, then drag to change time and volume values.
Right-click pointRight-click a point while the hand cursor is visible to delete it (anchors excluded).

Adjusting Levels

Add points and adjust them to shape volume over time. Pulling the line down attenuates volume, while dragging it up approaches original volume.

Applying Smooth Curves

Enabling **Curve** shapes the paths between points with smooth bezier curves. This is useful for creating organic fade-ins, fade-outs, or natural volume rises.

Recording offset

An audio device takes a small amount of time to capture your input and hand it to the app. Without compensation, recordings land slightly late against the backing track — Recording offset corrects that automatically.

Auto (default)Uses the latency the driver reports. Leave it on unless you have a reason not to.

Which mode should I use?

ExclusiveLowest latency, but the app takes over one device for input+output, so other apps are muted and the app sets the sample rate.
Low LatencyLow latency while other apps stay audible. The real figure depends on the driver.
Shared (default)Normal latency but the most stable, and it shares the device with other apps. Recommended for everyday use.
Lower latency trades away stability — if you hear dropouts or crackles, switch back to Shared.

  • 운영체제의 출력 장치와 볼륨을 확인합니다.

모든 트랙이 안 들리는데 레벨 미터는 움직일 때

저장된 출력 장치가 연결 해제된 경우입니다. Settings ▸ Audio Devices에서 지금 연결된 출력 장치를 다시 고르세요. 시작할 때 저장된 장치를 열지 못하면 앱이 시스템 기본 장치로 되돌리고 경고를 표시합니다.

프로젝트를 열었는데 NO SRC가 보일 때

원본 오디오 파일의 위치가 바뀌었을 가능성이 큽니다. 같은 파일을 그 트랙 위로 끌어다 놓거나 다시 가져오면 앱이 파일 이름·경로 기준으로 재연결합니다. 프로젝트를 통째로 옮길 때는 Save As…로 저장하면 녹음·바운스가 함께 모아져 안전합니다(2장).

녹음한 소리가 반주보다 늦게(또는 빠르게) 들릴 때

Settings ▸ Audio Devices ▸ Recording offset을 확인하세요. 기본값인 Auto가 대부분 맞지만, 어긋난다면 Auto를 끄고 ms 값을 직접 조정하거나, 귀로 맞춘 클립에서 오른쪽 클릭 ▸ Recording Offset Cal.로 그 값을 전역 설정에 반영하세요(12장).

녹음 중 소리가 끊기거나 지직거릴 때

버퍼가 너무 작거나 드라이버 모드가 불안정한 경우입니다. Buffer를 키우고, 모드를 Shared로 되돌려 보세요. 지연을 낮출수록 안정성은 떨어집니다(12장).

Record 버튼이 눌리지 않을 때

ARM된 Audio In 트랙이 없기 때문입니다. 녹음할 트랙의 ARM 버튼을 먼저 켜세요. Punch 버튼이 눌리지 않는다면 Repeat 구간이 없기 때문이고, 메트로놈이 눌리지 않는다면 프로젝트 BPM이 아직 없기 때문입니다(4장 · 6장).

프로젝트 폴더 용량이 계속 커질 때

여러 번 다시 녹음하면 쓰이지 않는 테이크 파일이 쌓입니다. Project ▸ Clean Up Unused Recordings…로 정리하세요. 되돌리기 기록에 남아 있는 파일은 제외되고, 삭제가 아니라 휴지통으로 이동합니다(2장).

MP3 저장이 실패할 때

MP3 인코딩은 앱에 함께 설치되는 변환기(ffmpeg)가 처리합니다. MP3 저장이 실패하면 ① 저장 위치에 쓰기 권한이 있는지(다른 폴더로 저장해 보기), ② 같은 이름의 파일이 다른 프로그램에서 열려 있지 않은지, ③ 디스크 여유 공간이 충분한지 확인하세요. 그래도 실패하면 WAV로 먼저 저장해 작업물을 안전하게 확보한 뒤, 앱을 다시 설치해 주세요.

화면이 너무 좁을 때

FocusDAW Studio의 최소 창 크기는 1258x600입니다. 믹서나 Export 창이 좁게 보이면 창을 넓히거나 타임라인을 스크롤해 필요한 영역을 확인하세요.

14. Troubleshooting

No Sound During Playback

  • Check if the track **M** (Mute) button is turned on.
  • Check if another track has its **S** (Solo) button active (which mutes all other tracks).
  • Check track faders and master volume fader levels.
  • Verify system audio output device settings and volume levels.

Nothing is audible but the meters still move

The saved output device has been disconnected. Pick a currently connected output under Settings ▸ Audio Devices. If the saved device cannot be opened at launch, the app falls back to the system default and shows a warning.

NO SRC appears after loading a project

The source audio has been moved or deleted. Drop the same file onto that track, or re-import it, and the app reconnects by name/path. When moving a project as a whole, save it with Save As… so its recordings and bounces travel with it (ch. 2).

Recordings land late (or early) against the backing

Check Settings ▸ Audio Devices ▸ Recording offset. The default Auto is right in most cases; otherwise turn Auto off and adjust the millisecond value, or align one clip by ear and use right-click ▸ Recording Offset Cal. to fold that into the global setting (ch. 12).

Dropouts or crackles while recording

The buffer is too small, or the driver mode is unstable on your system. Raise the Buffer and switch the mode back to Shared — lower latency always trades away stability (ch. 12).

The Record button will not press

There is no armed Audio In track — press ARM on the track you want to record. Likewise, Punch is disabled without a Repeat region, and the metronome is disabled until the project has a BPM (ch. 4 & 6).

The project folder keeps growing

Repeated re-recording leaves unused take files behind. Run Project ▸ Clean Up Unused Recordings…. Files still held by the undo history are excluded, and everything goes to the Recycle Bin rather than being erased (ch. 2).

MP3 Render Fails

MP3 encoding is handled by the converter (ffmpeg) that ships with the app. If an MP3 export fails, check that ① you can write to the destination folder (try another one), ② no other program has a file of the same name open, and ③ there is enough free disk space. If it still fails, export a WAV first to secure your work, then reinstall the app.

Elements cut off or window too small

The minimum window resolution is 1258x600. Resize your window or scroll horizontally on the timeline to locate hidden elements.
